UniGeom: Shared Geometry for World Models

Read the manuscript ↗

Independently trained models can describe the same world in different representation spaces. UniGeom studies whether their shared structure supports functional connections. We calibrate lightweight interfaces from common observations, freeze the base models, and evaluate how much prediction and control capability survives perception replacement. Experiments connect global representations, spatial token grids and a recurrent receiver, revealing how interface design and observation coverage affect the resulting behavior.
